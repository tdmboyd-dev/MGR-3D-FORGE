# Universal MGR-Native Inspiration Rule

Owner clarification (2026-10-25): **every external project is inspiration, never a request to clone its product or restrict MGR to its existing behavior.** This rule covers Scroll-World, God's Eye View, Pinokio, Synapse (after exact identification), and every future tool, repo, model, paper or workflow.

## Research-to-native transformation

For each verified source:

1. **Identify underlying primitive** — e.g., scroll-controlled time; scene-space awareness; local app orchestration; persistent relational memory.
2. **Extract general problem it solves** — immersive navigation, observation, deployment friction, continuity, etc.
3. **Invent a Forge-specific capability** — editable real geometry, world intelligence, safe model dock, memory across scenes. Extend beyond the upstream use case when grounded in feasible engineering.
4. **Separate factual input from hypothetical output** — observed, estimated, procedural, approved, license-restricted. A generated unseen back wall is an editable proposal, not a measured truth.
5. **Research licensing** at code, model weights, media, datasets and provider API layers independently. Source availability does not authorize copying all assets.
6. **Implement an original prototype**, test contracts and negative cases, benchmark local paths, then seek external Blender/engine and owner acceptance.
7. **Track honest status** in BUILD-REGISTER and PROGRESS-LOG. No feature receives a completed label because a third-party demo looks impressive.

## First examples

| Source | Underlying idea | MGR-native outcome | Current proof |
|---|---|---|---|
| Scroll-World | Continuous cinematic camera journey | Camera keyframes through actual Forge mesh world; future editable scroll/navigation director | `forge/cinematic.py` tested; no playback UI |
| God's Eye View | Spatial context and changing viewpoints | Spatial Eyes + evidence labels + invented editable interiors | `forge/perception.py` and `forge/interiors.py` tested; no real-world reconstruction |
| Pinokio | One-click local AI orchestration | License/budget-aware swappable model dock | `forge/recipes.py`, `forge/adapters.py` tested; no installer |
| Synapse (unresolved exact repo) | Pending evidence | No native feature assigned until exact upstream known | Unresolved, not a blocker |

**Direction:** MGR Forge is a native creator/renderer/asset system. New inspiration should make real authored worlds and characters more editable, persistent, reproducible, testable and affordable. Avoid one-off vendor-shaped clones.
