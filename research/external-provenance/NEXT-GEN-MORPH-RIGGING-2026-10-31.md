## Package admission and "unlimited" principles

1. **Core native zero-credit path:** Forge Python CPU geometry, morph, planning, checks + local Blender creation and independently reopened GLB. No provider credits; CPU/time/ram/storage/performance still finite. No paid API or GPU started by default.
2. **Separate Blender plug-in path:** Rigify, Rigger, CaptureForge and MPFB each pinned as standalone Blender add-ons, preserving GPL code and package notices and keeping proprietary core independently licensed. Review output and generated rigs separately.
3. **Isolated Linux GPU path:** install a specific model code/weights at pinned SHA in a versioned environment/container, after code/weight/encoder/dependency **folder-level** license acceptance and compute fit. No blind installer pipe-to-shell, no huge weight bundle checked into Git.
4. **Restricted/research path:** Adobe RigAnything, S-Lab MeshAnythingV2, SAM and Tencent models remain **not configured as commercially runnable** unless valid express permissions and all territories/output conditions are satisfied.
5. **Commercial API path:** Higgsfield/Tripo/Meshy APIs optional and paid only when explicitly approved with maximum cost, terms, provider receipts and reproducible output. A public MIT client does not grant open-source model weights or unlimited credits.
6. **Vault preservation:** source code and open assets can be mirrored only within their specific license scope; record each path's source version, URL, content hash, file license, permissions, and how the license was verified. An entire GitHub project does not inherit a nested `Assets/LICENSE` or vice versa. Keep one copy local plus independently verified off-site recovery after storage provision.
7. **Benchmark before "better than Meshy/Tripo":** same prompts/reference images and output format, multiple fixed cameras, anatomy/body proportions, surface realism, texture fidelity, mesh health, UV, bones/weights, animation deformation, user editability, consistency, costs and time. No unmeasured best-in-world claim.
